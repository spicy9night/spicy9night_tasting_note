# Cognac

### 【 為什麼內行人都追著這兩個區跑？大香檳區與邊緣區的秘密 🍷 】

干邑的世界很大，但如果你想直接攻頂，一定要認識這兩個「名字最響亮」的產區：

## 💎 大香檳區 (Grande Champagne) 它是干邑產區的皇冠！這裡的靈魂是來自古代海洋化石堆積而成的白堊質土壤（康巴尼亞土）。

味道特色： 口感極致細膩且輕盈，帶有豐富的花香。

因為結構紮實，它需要在橡木桶裡沈睡數十年，甚至半個世紀以上才能達到巔峰！

## 💜 邊緣區 (Borderies) 面積最小、最稀有，它是干邑的「花香炸彈」。這裡的土質屬於最古老的格羅伊土 (Groies)。

味道特色： 擁有獨一無二的「紫羅蘭」香氣，並伴隨著堅果與太妃糖的絲滑感。

這裡的生命之水口感圓潤，陳年速度相對較快，是許多頂級調和干邑的關鍵拼圖。

## 🍇 喝干邑，其實是在喝「葡萄」的堅持 根據 1936 年後的嚴格法規，干邑的品種可不能亂用：

法律限制： 絕大部分由白優尼 (Ugni Blanc) 組成，也可以加入白福兒 (Folle Blanche) 或哥隆拔 (Colombard)。

關鍵規範： 2011年後甚至規定，某些特定品種（如 Select）在混釀中最多只能占 10%。

💡 為什麼規定這麼嚴？ 為了確保「生命之水」在高酸度與低酒精濃度的狀態下進行二次蒸餾，這才能淬鍊出最純淨、最能代表風土的香氣。

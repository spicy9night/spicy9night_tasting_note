# Finest Selection Clynelish Casky 1996 28yo Refill Bourbon HHD 49.9%

### 【香氣】充滿了經典的蜂蠟、石蠟與粉蠟筆質感。隨之而來的是青蘋果汁、檸檬皮，以及淡淡的香草與花蜜香。
### 【味道】強而有力且質地豐富，带有標誌性的蠟感 (Waxy)。鹹鮮的礦石感 (Chalky) 與柑橘果香交織，展現出絕佳的平衡感。
### 【結語】非常悠長，帶有些許海風的鹹感、草本（如茴香）以及果醬的回甘。
### 【日期】2025.11.22 @高雄酒展
### 【價格】24000

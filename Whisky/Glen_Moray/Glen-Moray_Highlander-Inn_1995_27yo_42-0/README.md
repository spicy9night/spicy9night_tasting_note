# Glen Moray Highlander Inn 1995 27yo 42%

### 【結語】清澈如水
### 【日期】2025.11.22

### 官方介紹

Glen Moray 1995 27 Years Highlander Inn 格蘭莫雷 27年 高地人小酒館 台灣限定版 (700ml 42%) 

歷經三年疫情後，高地人小酒館特別慶祝重生的台灣限定版。館主皆川達也在數個高濃度的酒桶中，獨愛這款42%原桶強度的Glen Moray，沒有酒精濃度高低的迷思，純粹以酒質表現當作唯一考量。

1995年蒸餾入桶，2022年裝瓶，限量276瓶。從年份跟酒精度兩數值判讀，館主認為此橡木桶應該是陳放於一個接近於屋頂的乾熱環境，天使分享了較多酒精的同時，也讓此橡木桶內的威士忌更加熟成圓潤。

此酒款充滿熱帶水果風味，館主特別從高地人小酒館御用畫家Maggie的作品中，挑選出這款鳳梨作為酒標，以符合台灣身為水果王國的意象。

# 76.157_Behold The Beast_Deep rich and dried fruit Mortlach SMWS 2006 18yo 1st Oloroso butt 54.3%

### 【香氣】香蕉冰淇淋
### 【味道】香草奶油蛋糕
### 【日期】2025.11.22 @高雄酒展

官方品飲筆記

碰傷的蘋果重重落入盛滿白蘭地、糖漿與帶有獨特風味的蘭姆酒的大桶中，濺起的液滴灑落在浸著淺棕糖的無花果乾與香蕉麵包上。一股辛香的暖意席捲而來，帶來生薑、辣椒與白胡椒的層層瀑布，傾注進蘋果酸辣醬、葡萄乾以及帶有橙味苦精的煤焦油之中。加水後，釋放出草莓 daiquiri與法式馬丁尼雞尾酒的風味，點綴著罐頭桃子與黏稠新鮮松木的香氣。隨著果味酒體的個性成為舞台焦點，濃厚的雪莉酒韻味依然堅守到最後——在那裡，肉豆蔻、薑汁啤酒與果乾交織，並融合了巧克力橙餅乾的風味。

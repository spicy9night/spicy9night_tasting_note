# Omar OB 柳丁桶 56%

### 【香氣】柳丁皮油非常突出，聞起來像是剛削下來的柳丁皮與果皮精油，帶著濃烈的柑橘油脂感，還有一點乾果與成熟果香的底蘊，這支 OB 裝瓶的 Omar 在香氣上就很有辨識度。
### 【味道】入口後是百分百橘子感冒糖漿的感覺，甜中帶著濃厚的柑橘果味與皮脂感，像是把橘子皮、果肉和糖分一起壓縮成一口厚實的果醬。作為 56% 的 Single Malt，酒精的推力把這種柳丁桶帶來的果香和油感拉得更明顯，口感相當鮮明。
### 【結語】這次喝到的版本確實有點太偏向皮油與感冒糖漿的方向，讓整體風格比我印象中更重，也少了一些更像橘子果實本身的清爽與層次。雖然這樣的表現很有個性，但對我來說還是偏極端了一些，倒也因此成為一次很難忘的品飲記錄。

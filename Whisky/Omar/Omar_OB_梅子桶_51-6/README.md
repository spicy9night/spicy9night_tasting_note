# Omar OB 梅子桶 51.6%

### 【香氣】新鮮水果的感覺非常直接，梅子與百香果的果香一起湧上來，帶著一點清爽的酸甜氣息，這支 OB 裝瓶的 Omar 在香氣上就像一口剛剛採下來的熱帶與核果混合果實。
### 【味道】喝下去有梅子的生津感，酸甜的層次很明顯，還有百香果那種鮮明花果香氣在尾端跟著一起跑出來，酒體輕柔，沒有太厚重的壓迫感，反而讓這種果香顯得格外清爽。
### 【結語】這次喝到的版本很有趣，整體像是把新鮮水果的鮮甜和輕盈酒體完美綁在一起，酸甜感不會過頭，反而讓人覺得很舒服。作為一支以梅子桶為特色的 Omar，這次的表現相當有辨識度，也很適合在下午或天氣熱的時候慢慢品。

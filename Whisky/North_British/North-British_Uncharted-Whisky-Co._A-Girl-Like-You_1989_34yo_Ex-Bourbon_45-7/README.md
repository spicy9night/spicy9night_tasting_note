# A Girl Like You North British Uncharted Whisky Co. 1989 34yo Ex-Bourbon 45.7%

### 【香氣】明亮的水果香氣，帶有青草、夏日花香與青蘋果的清新感。
### 【味道】菠蘿翻轉蛋糕、檸檬冰糕的甜美，隨後出現肉豆蔻與肉桂的柔和香料。
### 【結語】水果風味在口中如跳跳糖般活潑，帶有泡騰感，最後留下熱帶果汁與檸檬冰糕的持久印象。
### 【日期】2025.11.22 @高雄酒展
### 【評分】75
